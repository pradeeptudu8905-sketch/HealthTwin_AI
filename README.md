# HealthTwin AI — Healthcare Digital Twin Prototype

## Project overview
HealthTwin AI is an educational proof-of-concept that combines **synthetic historical health records** with **simulated wearable sensor readings** to estimate whether a synthetic patient may experience an elevated-glucose event in the next two hours.

> **Important:** This is a demo built with synthetic data. It is not a medical device, has not been clinically validated, and must not be used for diagnosis or treatment.

## Competition requirements demonstrated
- Two data streams: historical patient records + changing wearable readings
- Machine-learning prediction pipeline
- Conceptual doctor-facing dashboard
- Synthetic data only
- Architecture documentation and demo instructions

## Technology stack
Python, Pandas, NumPy, scikit-learn, Streamlit, Plotly.

## Run locally
1. Install Python 3.10+.
2. Open a terminal in this project folder.
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Launch the app:
   ```bash
   streamlit run app.py
   ```
5. Open the local URL printed in the terminal.

## Files
- `app.py` — interactive dashboard
- `src/data.py` — creates synthetic EHR and wearable streams
- `src/model.py` — trains a toy risk model and estimates risk
- `docs/architecture_diagram.md` — architecture diagram source (Mermaid)
- `docs/demo_script.md` — suggested 20-minute demonstration plan
- `LICENSE` — MIT License

## Model and limitations
The model is trained on synthetic examples whose labels are generated by a transparent simulation rule. Its scores demonstrate a software workflow, not real-world clinical accuracy. Before any real clinical use, a model would require appropriate clinical data, expert oversight, rigorous validation, privacy/security review, and regulatory assessment.
